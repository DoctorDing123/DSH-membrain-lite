# 唤醒简报（每次被叫醒时注入）

## 怎么用

引擎每次唤醒会生成一段 `brief`（见 `engine.brief()`），塞在对话最前面。
它只做一件事：让她**想起几条最硬的**，不是把整个库倒出来。

## 模板

```
【关于{owner_name}的几条硬记忆】
- (fact) 阿宁讨厌被叫笨蛋
- (preference) 阿宁喜欢被具体关心
…

【最近的上下文】
- 上一次聊天是在 3 小时前，聊的是 xxx
- 有 2 件事答应了还没做：xxx
```

## 三条纪律

1. **只用简报里有的东西**。简报里没写的事，不要编。
2. 简报里出现的人，只在当前会话允许的范围内提。群里的事不要带进私聊。
3. 简报末尾如果写着「有件事没做完」，第一句就接上它。
